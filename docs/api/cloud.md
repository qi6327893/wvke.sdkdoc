# 云端接口

## 概述

云端接口用于承载开放平台的运营能力和云端数据交互能力，适合在驱动客户端、网页端或业务后台中对接账号、设备、配置同步、运营活动等服务。

当前分类作为云端能力的文档入口，后续具体接口会按照业务模块继续补充。

## 工具接口

- 设备与产品信息的云端查询。
- 驱动客户端配置、方案或用户数据的云端同步。
- 活动、素材、公告等运营内容的读取。
- 与开放平台业务后台相关的数据接口。

## 使用建议

TIP

- 云端接口通常需要服务端地址、鉴权方式和业务权限，请在接入前确认当前项目的开放范围。
- 客户端只应保存必要的会话信息，敏感密钥建议放在服务端处理。
- 与硬件实时通讯相关的能力请优先查看键盘、鼠标和固件升级接口分类。

## 生成 SN 号

CloudService.generateSn(options)

简要描述: 按起始序号和数量（或结束序号）生成范围内的 SN 号列表。

### 参数

| 字段 | 类型 | 描述 | 是否必需 |
|------|------|------|----------|
| options | object | 生成配置对象。 | 否 |

`options` 对象属性：

| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| format | string | `"0001"` | 格式化模板，用 `0` 表示数字占位；设为 `"weekly"` 启用周次 SN 格式。
| start | number | `1` | 起始序号。 |
| end | number | — | 结束序号（含），与 `count` 二选一。 |
| count | number | `1` | 生成数量，与 `end` 二选一。 |
| maxLength | number | `20` | 最大输出 ASCII 字节数。 |
| weekly | boolean | — | 设为 `true` 启用周次 SN 格式（与 `format` 互斥）。 |
| manufacturer | string | `"C"` | 厂商代号（仅 weekly 模式）。`C`=CIY，`S`=Sunrex。 |
| sku | string | `"K1"` | 物料编号（仅 weekly 模式）。`K1` 对应物料 K001，`M1` 对应物料 M001。 |
| year | number | 当前年 | 公历年份（仅 weekly 模式）。 |
| week | number | 当前周 | ISO 周序号 1–53（仅 weekly 模式）。 |

### 返回值

• 总体类型: `string[]`
• 描述: 返回生成的 SN 号数组。

### 使用示例 - 基本格式

```javascript
import { CloudService } from 'wvke-sdk';

// 默认：从 0001 开始生成 1 个
CloudService.generateSn();                          // ['0001']

// 指定起始和数量
CloudService.generateSn({ start: 1, count: 5 });
// ['0001', '0002', '0003', '0004', '0005']

// 指定起始和结束
CloudService.generateSn({ format: 'SN-0000', start: 10, end: 12 });
// ['SN-0010', 'SN-0011', 'SN-0012']
```

### 使用示例 - 周次 SN 格式

周次 SN 格式适用于按周次区分的唯一产品编号场景，输出格式为：

```text
C M1 39 89 0001
│ │  │  │  └─ 唯一连续编号（4 位）
│ │  │  └─ 周次编码
│ │  └─ 年份编码
│ └─ 物料料号（SKU）
└─ 厂商代号
```

#### 唯一连续编号 ID

采用 4 位十进制计数器，取值范围 0000～9999；若单周内 0000–9999 编号容量不足，则启用 36 进制编码段，编码区间为 AAAA～ZZZZ（0-9 + A-Z）。

编码排序示例：`0001~9999`、`A001~Z999`、`AA00~ZZ99`……

#### 周次编码

取值范围 01–53，取自标准日历周序号，再固定加 37；示例：第 52 自然周编码为 `89`（52+37=89），第 01 自然周编码为 `38`。

#### 年份编码

取公历年份后两位数字，固定加 13；示例：2026 年编码为 `39`（26+13=39），2027 年编码为 `40`。

#### 物料料号 / 零件编号（SKU/PN）

`M1` 对应物料 `M001`，`K1` 对应物料 `K001`，其余编码规则待定。

#### 厂商代号

`S` 代表长荣（Sunrex），`C` 代表 CIY，其余厂商代号待定。

```javascript
import { CloudService } from 'wvke-sdk';

// 启用周次格式（默认使用当前日期、厂商 C、物料 K1）
CloudService.generateSn({ weekly: true, count: 3 });
// ['C K1 39 65 0001', 'C K1 39 65 0002', 'C K1 39 65 0003']
// 39=2026年编码，65=当前周（28+37）

// 通过 format 快捷启用
CloudService.generateSn({ format: 'weekly', manufacturer: 'S', count: 2 });
// ['S M1 39 65 0001', 'S M1 39 65 0002']

// 指定厂商/物料和年份/周次
CloudService.generateSn({ weekly: true, manufacturer: 'C', sku: 'K1', year: 2026, week: 52, start: 1, count: 3 });
// ['C K1 39 89 0001', 'C K1 39 89 0002', 'C K1 39 89 0003']
// 89=第52周编码（52+37）

// 超 9999 自动切换 36 进制编码
CloudService.generateSn({ weekly: true, count: 5, start: 9998 });
// ['...9998', '...9999', '...A7PS', ...]
```
