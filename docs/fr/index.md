# wvke-sdk

wvke-sdk est un SDK JavaScript pour communiquer avec les périphériques gaming, y compris les claviers et les souris.

Construit sur la technologie moderne WebHID, il permet une personnalisation approfondie et un contrôle intelligent des claviers, souris et autres périphériques. Il accélère la livraison de bout en bout des produits périphériques gaming et ouvre de nouvelles possibilités dans l'écosystème gaming. Le projet est développé et maintenu par le GDE Game Driver Engine Team.

## Types de SDK

### ⌨️ Clavier linéaire

Conçu pour les claviers mécaniques :

- Mappage des touches et changement de couche
- Contrôle d'éclairage RGB
- Autorisation WebHID, liste des appareils autorisés et initialisation
- Interrupteur de course complète RT, réglage de course et zone de sécurité
- Enregistrement et lecture de macros
- Réglage du taux d'interrogation (1KHz-8KHz)
- Changement de mode système (Windows/Mac)

### 🖱️ SDK Souris

Conçu pour les souris gaming :

- Réglage DPI (400-16000 DPI)
- Programmation des boutons et macros
- Personnalisation de l'éclairage RGB
- Réglage de la distance de décollage
- Optimisation de l'interrogation

## Caractéristiques

- Support JavaScript/TypeScript moderne
- Communication matérielle WebHID
- APIs complètes de contrôle d'éclairage
- APIs de mappage des touches et macros
- APIs de course RT, touches avancées et initialisation
- APIs DPI et mappage des boutons de souris
- Service de mise à jour personnalisée générale
- Documentation API détaillée
