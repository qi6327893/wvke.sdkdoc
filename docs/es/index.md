# wvke-sdk

wvke-sdk es un SDK de JavaScript para comunicarse con periféricos gaming, incluidos teclados y ratones.

Construido sobre la moderna tecnología WebHID, permite la personalización profunda y el control inteligente de teclados, ratones y otros periféricos. Acelera la entrega de productos periféricos gaming y abre nuevas posibilidades en el ecosistema gaming. El proyecto es desarrollado y mantenido por el GDE Game Driver Engine Team.

## Tipos de SDK

### ⌨️ Teclado lineal

Construido para teclados mecánicos:

- Mapeo de teclas y cambio de capa
- Control de iluminación RGB
- Autorización WebHID, lista de dispositivos autorizados e inicialización
- Interruptor de recorrido completo RT, ajuste de recorrido y zona segura
- Grabación y reproducción de macros
- Ajuste de tasa de sondeo (1KHz-8KHz)
- Cambio de modo de sistema (Windows/Mac)

### 🖱️ SDK de ratón

Construido para ratones gaming:

- Ajuste DPI (400-16000 DPI)
- Programación de botones y macros
- Personalización de iluminación RGB
- Ajuste de distancia de elevación
- Optimización de sondeo

## Características

- Soporte moderno de JavaScript/TypeScript
- Comunicación hardware WebHID
- APIs completas de control de iluminación
- APIs de mapeo de teclas y macros
- APIs de recorrido RT, teclas avanzadas e inicialización
- APIs de DPI y mapeo de botones de ratón
- Servicio de actualización personalizada general
- Documentación API detallada
