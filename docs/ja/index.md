# wvke-sdk

wvke-sdk は、キーボードやマウスなどのゲーミングペリフェラルと通信するための JavaScript SDK です。

最新の WebHID テクノロジースタックをベースに、キーボード、マウス、その他ペリフェラルの高度なカスタマイズとインテリジェント制御を実現します。ゲーミングペリフェラル製品のエンドツーエンドの提供を加速し、ゲーミングエコシステム全体に新たな可能性を開くことを目的としています。本プロジェクトは GDE Game Driver Engine Team によって開発・保守されています。

## SDK タイプ

### ⌨️ リニアキーボード

メカニカルキーボード向けに構築：

- キーマッピングとレイヤー切り替え
- RGB ライティング制御
- WebHID 認証、認証済みデバイス一覧、デバイス初期化
- RT 全行程スイッチ、作動トラベル、セーフゾーン調整
- マクロ記録と再生
- ポーリングレート調整（1KHz-8KHz）
- システムモード切替（Windows/Mac）

### 🖱️ マウス SDK

ゲーミングマウス向けに構築：

- DPI 調整（400-16000 DPI）
- ボタンプログラミングとマクロ
- RGB ライティングカスタマイズ
- リフトオフ距離調整
- ポーリング最適化

## 特徴

- モダンな JavaScript/TypeScript サポート
- WebHID ハードウェア通信
- 完全なライティング制御 API
- キーマッピングとマクロ API
- RT トラベル、高度なキー API、デバイス初期化
- マウス DPI とボタンマッピング API
- 汎用カスタムアップグレードサービス
- 詳細な API ドキュメント

## チュートリアル

```bash
npm install wvke-sdk
```

詳細な使い方は [API ドキュメント](/ja/api/info) をご参照ください。
