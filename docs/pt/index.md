# wvke-sdk

wvke-sdk é um SDK JavaScript para comunicação com periféricos gamer, incluindo teclados e mouses.

Construído sobre a moderna tecnologia WebHID, permite personalização profunda e controle inteligente de teclados, mouses e outros periféricos. Acelera a entrega de produtos periféricos gamer e abre novas possibilidades no ecossistema gamer. O projeto é desenvolvido e mantido pelo GDE Game Driver Engine Team.

## Tipos de SDK

### ⌨️ Teclado Linear

Construído para teclados mecânicos:

- Mapeamento de teclas e troca de camada
- Controle de iluminação RGB
- Autorização WebHID, lista de dispositivos autorizados e inicialização
- Interruptor de curso completo RT, ajuste de curso e zona segura
- Gravação e reprodução de macros
- Ajuste de taxa de polling (1KHz-8KHz)
- Troca de modo de sistema (Windows/Mac)

### 🖱️ SDK Mouse

Construído para mouses gamer:

- Ajuste DPI (400-16000 DPI)
- Programação de botões e macros
- Personalização de iluminação RGB
- Ajuste de distância de levantamento
- Otimização de polling

## Características

- Suporte moderno a JavaScript/TypeScript
- Comunicação de hardware WebHID
- APIs completas de controle de iluminação
- APIs de mapeamento de teclas e macros
- APIs de curso RT, teclas avançadas e inicialização
- APIs DPI e mapeamento de botões de mouse
- Serviço de atualização personalizada geral
- Documentação API detalhada
