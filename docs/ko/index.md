# wvke-sdk

wvke-sdk는 키보드와 마우스를 포함한 게이밍 주변기기와 통신하기 위한 JavaScript SDK입니다.

최신 WebHID 기술 스택을 기반으로 키보드, 마우스 및 기타 주변기기의 심층 맞춤 설정과 지능형 제어를 가능하게 합니다. 게이밍 주변기기 제품의 엔드투엔드 제공을 가속화하고 게이밍 생태계 전반에 새로운 가능성을 열어줍니다. 이 프로젝트는 GDE Game Driver Engine Team이 개발 및 유지 관리합니다.

## SDK 유형

### ⌨️ 리니어 키보드

기계식 키보드용으로 구축:

- 키 매핑 및 레이어 전환
- RGB 조명 제어
- WebHID 인증, 인증 장치 목록, 장치 초기화
- RT 전행정 스위치, 작동 트래블, 세이프 존 조정
- 매크로 기록 및 재생
- 폴링 레이트 조정 (1KHz-8KHz)
- 시스템 모드 전환 (Windows/Mac)

### 🖱️ 마우스 SDK

게이밍 마우스용으로 구축:

- DPI 조정 (400-16000 DPI)
- 버튼 프로그래밍 및 매크로
- RGB 조명 커스터마이징
- 리프트오프 거리 조정
- 폴링 최적화

## 특징

- 최신 JavaScript/TypeScript 지원
- WebHID 하드웨어 통신
- 완전한 조명 제어 API
- 키 매핑 및 매크로 API
- RT 트래블, 고급 키 API, 장치 초기화
- 마우스 DPI 및 버튼 매핑 API
- 범용 사용자 정의 업그레이드 서비스
- 상세한 API 문서

## 튜토리얼

```bash
npm install wvke-sdk
```

자세한 사용법은 [API 문서](/ko/api/info)를 참조하세요.
