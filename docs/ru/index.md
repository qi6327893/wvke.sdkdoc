# wvke-sdk

wvke-sdk — это JavaScript SDK для связи с игровыми периферийными устройствами, включая клавиатуры и мыши.

Построенный на современном стеке технологий WebHID, он обеспечивает глубокую настройку и интеллектуальное управление клавиатурами, мышами и другими периферийными устройствами. SDK ускоряет сквозную поставку игровых периферийных продуктов и открывает новые возможности в игровой экосистеме. Проект разрабатывается и поддерживается командой GDE Game Driver Engine Team.

## Типы SDK

### ⌨️ Линейная клавиатура

Создана для механических клавиатур:

- Маппинг клавиш и переключение слоев
- Управление RGB-подсветкой
- Авторизация WebHID, список авторизованных устройств, инициализация
- Переключатель полного хода RT, настройка хода и безопасной зоны
- Запись и воспроизведение макросов
- Регулировка частоты опроса (1KHz-8KHz)
- Переключение режима системы (Windows/Mac)

### 🖱️ SDK Мыши

Создан для игровых мышей:

- Регулировка DPI (400-16000 DPI)
- Программирование кнопок и макросы
- Настройка RGB-подсветки
- Регулировка высоты отрыва
- Оптимизация опроса

## Возможности

- Современная поддержка JavaScript/TypeScript
- Аппаратная связь через WebHID
- Полные API управления подсветкой
- API маппинга клавиш и макросов
- API хода RT, расширенных клавиш и инициализации
- API DPI и маппинга кнопок мыши
- Сервис пользовательского обновления
- Детальная документация API

## Учебник

```bash
npm install wvke-sdk
```
