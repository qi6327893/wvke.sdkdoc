# wvke-sdk

wvke-sdk è un SDK JavaScript per comunicare con periferiche gaming, inclusi tastiere e mouse.

Costruito sulla moderna tecnologia WebHID, consente la personalizzazione profonda e il controllo intelligente di tastiere, mouse e altre periferiche. Accelera la consegna end-to-end dei prodotti periferiche gaming e apre nuove possibilità nell'ecosistema gaming. Il progetto è sviluppato e mantenuto dal GDE Game Driver Engine Team.

## Tipi di SDK

### ⌨️ Tastiera Lineare

Costruita per tastiere meccaniche:

- Mappatura dei tasti e cambio livello
- Controllo illuminazione RGB
- Autorizzazione WebHID, elenco dispositivi autorizzati e inizializzazione
- Interruttore a corsa completa RT, regolazione corsa e zona di sicurezza
- Registrazione e riproduzione di macro
- Regolazione frequenza di polling (1KHz-8KHz)
- Cambio modalità sistema (Windows/Mac)

### 🖱️ SDK Mouse

Costruito per mouse gaming:

- Regolazione DPI (400-16000 DPI)
- Programmazione pulsanti e macro
- Personalizzazione illuminazione RGB
- Regolazione distanza di sollevamento
- Ottimizzazione polling

## Caratteristiche

- Supporto moderno JavaScript/TypeScript
- Comunicazione hardware WebHID
- API complete per il controllo dell'illuminazione
- API per mappatura tasti e macro
- API corsa RT, tasti avanzati e inizializzazione
- API DPI e mappatura pulsanti mouse
- Servizio di aggiornamento personalizzato generale
- Documentazione API dettagliata

## Tutorial

npm install wvke-sdk
